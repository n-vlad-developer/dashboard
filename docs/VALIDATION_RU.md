# Изменения и границы проверки

## Выполнено

- Один React Dashboard для рабочих и синтетических данных вместо отдельной урезанной демостраницы.
- Семь разделов, пять ресурсов меню, создание/редактирование, фильтры и пагинация, перевод, расчёт отчётов, повтор неуспешного задания, CSV/JSON/XLSX.
- Фирменный акцент `#cae213`, тёмный текст на лаймовых кнопках; фиолетовый оставлен вторичным цветом графиков и информационных элементов. Статусы сохраняют смысловые цвета.
- Локальный Manrope, единый React-календарь, мобильные карточки вместо широких таблиц каталога/истории/заданий; drawer вынесен через React Portal.
- Удалены повторяющиеся верхние обновления для разделов со своим обновлением, декоративная звёздочка в заголовках, отдельная старая демостраница и статические preview-файлы.
- Перенесены оригинальные загрузка, экран ошибок с котом, SVG/PNG иконки и социальная обложка из предоставленного Q1 (`Desktop.rar`).
- Обработаны loading, error, global-error и 404; анимации учитывают reduced motion. Подписи форм связаны с полями; редактор и мобильная навигация удерживают клавиатурный фокус.
- Open Graph, Twitter Card, favicon SVG/32 px, Apple touch icon, manifest и theme-color. Кабинет закрыт от индексирования.
- Исходники отформатированы; стили, бренд, навигация, демо и серверные функции разделены по каталогам.

## Безопасность

- Удалён фиксированный `SESSION_SECRET` из примера; использование старого образца блокируется. Если он установлен на сервере, требуется замена уникальным значением.
- Origin / Fetch Metadata проверяются для всех изменяющих API-запросов, включая вход и выход. Подход сверён с [OWASP CSRF Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html).
- Ограничение реального объёма тела запроса: 16 KiB для авторизации, 11 MiB для прокси с изображениями; не только проверка Content-Length.
- Серверные запросы имеют таймаут и не следуют редиректам с Bearer-токеном.
- Ротация refresh-токена сохраняется. Токены остаются в зашифрованной HttpOnly cookie, с Secure в production и SameSite=Lax.
- Ошибки сервера не отдают клиенту техническое содержимое 5xx. JSON-прокси не возвращает HTML от upstream. Экспорт сохраняется отдельным файловым ответом.
- Защитные заголовки nosniff, DENY/frame-ancestors, base-uri, object-src, form-action, Referrer-Policy, Permissions-Policy.
- Разрешённые API-пути и методы по-прежнему перечислены явно; анонимные обращения отклоняются.

Это аудит клиентского проекта и его BFF-прокси, не пентест инфраструктуры. Права доступа к объектам, ограничения попыток входа и ограничения загрузок на самом Q1 API должны обеспечиваться сервером. Его исходники/рабочая учётная запись не предоставлены, поэтому реальные вход, OTP, межтенантные права и интеграции не проверены.

## Проверки

Автотесты: версии и суммы аналитики, фильтры, получасовые интервалы, CRUD и конфликт версий, изоляция заведений, детали вызова, отчёты/задания/перевод, содержимое JSON/CSV/XLSX, CSRF, анонимный доступ, заголовки и метаданные. Браузерные сценарии: семь разделов на четырёх ширинах, календарь, создание и повторное редактирование после перезагрузки, отсутствие запросов демо к API, повтор неуспешного задания и 404 Q1.

Chromium и WebKit запускаются в Windows. Firefox ранее завершился ошибкой запуска окружения `spawn UNKNOWN`; он не считается проверенным. Физические macOS, iOS и Android недоступны. Одинаковая компоновка проверяется по ширинам и двум движкам, но побитовое совпадение сглаживания текста между ОС не обещается.

Скриншоты находятся в `docs/screenshots/`. Финальные результаты команд фиксируются в `docs/check-results.txt`.

## Заставка: один запуск

Убрана вторая анимированная заставка из loading маршрута. Кабинет монтируется под недоступным для взаимодействия оверлеем заранее. React запускает одну временную шкалу после загрузки шрифтов и двух кадров отрисовки; смена разделов и получение данных не перезапускают её. Полное обновление документа запускает заставку заново. Удалена неиспользуемая зависимость framer-motion. Chromium и WebKit подтвердили ровно один экземпляр заставки и готовность кабинета до её закрытия.
