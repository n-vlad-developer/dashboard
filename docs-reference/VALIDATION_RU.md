# Проверки выпуска v7

## Выполнено

- Автотесты Django/DRF на отдельной SQLite БД с применением миграций. В набор включены проверки аналитики v6, наследуемые проверки API v7 и новые сценарии. Число выполненных тестов приведено в tests.log.
- Межсетевой/межзаведенческий доступ, изменения разрешений, запрет аналитики администратору, logout и refresh, запрет использования отозванной сессии через прежний API аналитики.
- Создание полного дерева меню: меню → категория → блюдо → группа → модификатор, синоним. Защита связей, запрет DELETE, optimistic concurrency через If-Match, очистка изображения.
- Просрочка в режиме без меток, принятие просроченного вызова, автозакрытие только после таймаута от принятия, запрет ручного закрытия другим сотрудником; общий счётчик закрытий.
- Состав смен при создании вызова и срок завершения поздно открытой смены для ночного графика.
- Перевод с имитацией ответа AI: заполнение пустых языков, сохранение исходного языка, отсутствие повторного выполнения задания, идемпотентность HTTP-запроса и квота.
- Фоновый общий пересчёт; границы дней/DST, пересекающиеся смены, неполные дни, взвешенные средние, периодические отчёты.
- Django system check, соответствие новых моделей миграциям, компиляция Python. Серверный рендер главной страницы админки, списков заведений, меню, политик и заданий.

## Что этой проверкой не подтверждается

Не выполнялись миграции на вашей рабочей PostgreSQL, нагрузочные/конкурентные тесты PostgreSQL, запуск служб Windows/NSSM/IIS, реальные push, платный запрос OpenAI и проверка действующего мобильного клиента. SQLite не доказывает поведение row-lock под конкурентной нагрузкой PostgreSQL. Эти проверки выполнить на копии рабочего окружения по INSTALL_RU.md.

Глобальный шаблон Django Admin приведён к общему оформлению (светлая/тёмная тема, шрифты, отступы, кнопки и таблицы), но визуальное сравнение всех экранов в браузерах не проводилось. Клиентский дашборд не создавался: подготовлены API и документация.

В архив не включены `.env`, media, база данных, секреты окружения или журналы рабочего проекта. tests.log содержит только синтетические тестовые исключения: Invalid/Zone и RuntimeError(test) ожидаемы в проверках обработки ошибок, итог запуска должен быть OK.

## Важные ограничения данных

Старая история без снимков не дополняется вымышленным составом смен. Просроченный принятый вызов не означает вину сотрудника, который его принял. Автозакрытие не является точным временем окончания обслуживания. Нет фиктивного рейтинга качества или процента занятости столов. Нагрузка представлена количеством вызовов, часами сотрудников, вызовами на час и временными рядами.

Квота AI ограничивает объём текста и число заданий, не гарантирует фиксированную сумму счёта провайдера. Задания после сбоя автоматически повторно не оплачиваются. Если процесс оборвался после части переводов, они остаются; повтор создаётся пользователем осознанно.
