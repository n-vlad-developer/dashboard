# Изменения относительно исходников и v6

- Новое приложение apps.dashboard: политики заведений, недельный график, сессии JWT, API меню/аналитики/истории, задания перевода и пересчёта.
- horeсa_core/settings/base.py и urls.py: регистрация приложения и маршрута, CORS-заголовки, фоновые расписания и очередь q1_background. Проверка dashboard-сессии встроена в стандартную JWT-аутентификацию, мобильные JWT без dashboard_session сохраняют прежнюю схему проверки.
- calls: снимок состава смен и настроек в момент создания; контроль принимающего при ручном закрытии; транзакционная блокировка при принятии/закрытии; просрочка без зависимости от меток; фоновый повторный контроль таймеров; подпись arrived = «Принят».
- shifts: завершение по графику заведения с ночным переходом и запасом; показатели относятся к принявшему сотруднику своей смены; условный performance_score больше не рассчитывается.
- payments/payment_flow.py и calls/services/auto_cleanup.py: оплата/закрытие смены не используются как основание закрыть необслуженный вызов.
- analytics: версия расчётов 7; closed включает auto_closed; периодические отчёты читают актуальную версию; строки смен связываются и по shift, и по сотруднику; готовые ряды по дням/получасам и справочник метрик.
- Главная админка: общий базовый шаблон, карточка настройки кабинета и расписания, ссылка из заведения, очередь заданий и двухшаговый запуск общего пересчёта.
- notifications/0003: исправлена зависимость на миграцию, добавляющую platform. Подробности совместимости в INSTALL_RU.md.

Не добавлялись новые платные AI-функции генерации меню для клиентов. Работающие внешние интеграции не заменяются; редактирование синхронизированных меню по умолчанию запрещено. В архиве представлены полные исходники, а не только перечисленные файлы.
